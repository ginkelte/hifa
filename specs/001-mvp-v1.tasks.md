# Tasks: hifa v1 — local tracker (CLI + SQLite + dashboard)

Based on: SPEC-001 (spec_revision 9)
Acceptance criteria: `specs/acceptance/001-mvp-v1/` — **17 `.feature` files**, one `Feature` per
file (D-020), 187 scenarios (175 `Scenario` + 12 `Scenario Outline`, each outline counted once).
There is no standalone `.feature`.
Order: strictly sequential; each task assumes the previous ones merged and with green tests.
Tie-breaker rule: **the DDL and the schema are those of `specs/010-data-model.md`** (D-008). If a
task of this file and `010-data-model.md` diverge, `010` wins. The exit codes are those of D-014 and
the public contracts those of the component specs (030, 040, 050, 060, 070, 080, 090, 100) —
SPEC-001 does not define contracts (D-005).

Mandatory layout: **`src/hifa/` of SPEC-000 §4.3** (`domain/`, `ports.py`, `app/`,
`adapters/sqlite/`, `cli/`, `api/`, `web/`, `config.py`). Changing that structure is a bump of
`version`; this plan does not change it.

- Note: the script prints one `DEBT`/`EXEMPT`/`FAIL` line per row and a final

      the other contracts, and the operational rows declared today are `init` and `serve`.
